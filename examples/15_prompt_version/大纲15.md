# 六、在配置中增加 Prompt 版本

## 1. 修改 `.env`

增加：

```env
PROMPT_VERSION=v2
```

例如：

```env
OPENAI_API_KEY=你的API_KEY
OPENAI_BASE_URL=你的BASE_URL
MODEL_NAME=你的模型名称
TEMPERATURE=0
MAX_TOKENS=800
PROMPT_VERSION=v2
```

> 注意：`.env` 通常不应该提交到 Git 仓库，尤其不要提交真实 API Key。

---

## 2. 修改 `config.py`

```python
import os

from dotenv import load_dotenv

load_dotenv()


class Settings:
    api_key = os.getenv("OPENAI_API_KEY")
    base_url = os.getenv("OPENAI_BASE_URL")
    model_name = os.getenv("MODEL_NAME", "")
    temperature = float(os.getenv("TEMPERATURE", "0"))
    max_tokens = int(os.getenv("MAX_TOKENS", "800"))
    prompt_version = os.getenv("PROMPT_VERSION", "v1")


settings = Settings()
```

这样以后只修改：

```env
PROMPT_VERSION=v1
```

或者：

```env
PROMPT_VERSION=v2
```

就可以切换 Prompt。

# 七、修改 Service，按配置选择 Prompt

修改：

```text
app/services/log_service.py
```

参考代码：

```python
from openai import OpenAI

from app.exceptions import LLMServiceError, StructuredOutputError
from app.models import ErrorAnalysis
from app.prompts import PROMPT_REGISTRY
from config import settings


client = OpenAI(
    api_key=settings.api_key,
    base_url=settings.base_url,
)


def get_prompt_config() -> dict:
    prompt_config = PROMPT_REGISTRY.get(settings.prompt_version)

    if prompt_config is None:
        raise ValueError(
            f"不存在的 Prompt 版本：{settings.prompt_version}"
        )

    return prompt_config


def analyze_log(log_text: str) -> ErrorAnalysis:
    prompt_config = get_prompt_config()

    try:
        response = client.beta.chat.completions.parse(
            model=settings.model_name,
            messages=[
                {
                    "role": "system",
                    "content": prompt_config["system"],
                },
                {
                    "role": "user",
                    "content": prompt_config["user_template"].format(
                        log_text=log_text
                    ),
                },
            ],
            response_format=ErrorAnalysis,
            temperature=settings.temperature,
            max_tokens=settings.max_tokens,
        )
    except Exception as exc:
        raise LLMServiceError("模型调用失败") from exc

    message = response.choices[0].message

    if getattr(message, "refusal", None):
        raise StructuredOutputError(
            f"模型拒答：{message.refusal}"
        )

    if message.parsed is None:
        raise StructuredOutputError(
            "模型没有返回可解析的结构化结果"
        )

    return message.parsed
```

# 十、练习 3：给 Prompt 增加版本信息

class ErrorAnalysis(BaseModel):

result.prompt_version = settings.prompt_version

# 十四、今天最重要的理解

今天不是在学习一个新的框架。

真正要建立的是一种**AI 应用工程化思维**：

```text
原来的方式：

业务代码
   ↓
写死 Prompt
   ↓
调用模型
   ↓
得到结果
```

逐渐变成：

```text
配置
├── model_name
├── temperature
├── max_tokens
└── prompt_version
        ↓
Prompt Registry
├── v1
├── v2
└── ...
        ↓
LLM Service
        ↓
Structured Output
        ↓
统一结果
        ↓
记录 model + prompt_version
```

以后如果出现：

> “昨天这个日志分析得挺好，今天怎么分析结果变了？”

就可以进一步追踪：

```text
输入日志
    ↓
model_name
    ↓
prompt_version
    ↓
temperature
    ↓
response schema
    ↓
模型输出
```

这就是从“调用大模型”逐渐走向“开发 AI 应用”。
