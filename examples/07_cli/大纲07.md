```text
    ↓

```

第一周结束时，需要能够区分以下几个概念：

| 层次   | 含义                    |
| ---- | --------------------- |
| 调用成功 | API 正常返回了模型内容         |
| 解析成功 | 返回内容能够转换成 JSON        |
| 结构成功 | JSON 字段符合 Pydantic 模型 |
| 业务合格 | 原因、建议数量和内容达到基本要求      |

> **重点：**
>
> “模型返回了 JSON” ≠ “结果可靠”。
>
> “Pydantic 校验通过” ≠ “业务结果一定正确”。

# 四、今天写什么代码

新建 `cli.py`：

```python
import argparse

from log_analyzer import analyze_log
from prompt_eval import score_analysis, validate_analysis


def main():
    parser = argparse.ArgumentParser(
        description="Java 错误日志分析器"
    )

    parser.add_argument(
        "--log",
        required=True,
        help="要分析的错误日志",
    )

    args = parser.parse_args()

    try:
        result = analyze_log(args.log)
        warnings = validate_analysis(result)
        score = score_analysis(result)

        print("\n========== 分析结果 ==========")

        print("错误类型：", result.error_type)

        print("\n可能原因：")
        for cause in result.possible_causes:
            print("-", cause)

        print("\n解决建议：")
        for suggestion in result.suggestions:
            print("-", suggestion)

        print("\n质量评分：", score)

        if warnings:
            print("\n质量提醒：")
            for warning in warnings:
                print("-", warning)
        else:
            print("\n结果通过基础质量检查")

    except Exception as exc:
        print("分析失败：", exc)


if __name__ == "__main__":
    main()
```

如果你的 `validate_analysis()` 和 `score_analysis()` 目前位于其他文件中，直接调整 import 路径即可。

**今天的重点不是文件名，而是职责拆分：**

* `log_analyzer.py`：调用模型
* `prompt_eval.py`：校验和评分
* `cli.py`：用户交互

```python
if args.file:
    with open(args.file, "r", encoding="utf-8") as file:
        logs = [line.strip() for line in file if line.strip()]

    for log in logs:
        print(f"\n正在分析：{log}")

        try:
            result = analyze_log(log)
            print(
                result.model_dump_json(
                    indent=2,
                    ensure_ascii=False
                )
            )
```
