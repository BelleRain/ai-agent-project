# Day 5｜批量日志分析与错误类型统计：学习验收标准

## 一、核心目标

将单条日志分析能力扩展为批量处理能力，理解批量数据处理、结果汇总和大模型输出一致性三个重要问题。

今天的重点不是增加多少代码，而是理解：**如何将一次大模型调用组织成一个可重复执行、能够汇总结果的程序。**

## 二、必须掌握的核心知识

### 1. 批量处理：为什么需要 `results`？

单条日志分析函数 `analyze_log()` 负责处理一条日志，批量分析函数 `analyze_logs()` 则负责组织多次调用。

```python
results = []

for log_text in logs:
    result = analyze_log(log_text)
    results.append(result)

return results
```

必须理解：

- `analyze_log()` 的输入是一条日志，返回一个分析结果。
- `analyze_logs()` 的输入是多条日志，返回多个分析结果组成的列表。
- `results` 用于保存每次调用成功产生的结果。
- `append()` 将单次分析结果加入列表。
- `return results` 将完整的结果集合交还给调用者。

**核心认知：** 单条处理函数负责具体业务，批量处理函数负责组织流程。这种职责划分有利于代码复用、测试和后续扩展。

### 2. 异常处理：为什么不能让一条日志影响全部任务？

```python
for log_text in logs:
    try:
        result = analyze_log(log_text)
        results.append(result)
    except Exception as exc:
        print(f"分析失败：{exc}")
```

必须理解：

- `try` 中放置可能发生异常的操作。
- `except` 用于捕获指定范围内的异常。
- 将异常处理放在循环内部，可以让单条日志失败后继续尝试后续日志。
- 只有成功获得的分析结果才会被添加到 `results`。

需要注意：`except Exception` 适合初学阶段理解流程，但生产代码通常应捕获更具体的异常，并记录失败日志、重试次数和失败原因。

**核心认知：** 局部任务失败不一定意味着整个批处理任务失败。异常处理策略应当与业务对失败的容忍程度相匹配。

### 3. 字典计数：如何统计错误类型？

```python
counter = {}

for result in results:
    error_type = result.error_type
    counter[error_type] = counter.get(error_type, 0) + 1

return counter
```

必须理解：

- `counter = {}` 创建一个空字典。
- `result.error_type` 获取当前分析结果的错误类型。
- `counter.get(error_type, 0)` 获取当前计数；不存在时返回 `0`。
- `+ 1` 表示又发现了一条对应类型的错误。
- 最终返回的字典记录每种错误类型及其出现次数。

Java 对应思路：

```java
counter.put(
    errorType,
    counter.getOrDefault(errorType, 0) + 1
);
```

**核心认知：** 字典适合将一个分类标识映射到一个统计值。相同的键会累加，不同的键会分别统计。

### 4. 大模型输出：为什么相同日志可能统计成两类？

例如，两次输入的日志完全相同：

```text
Communications link failure
Communications link failure
```

但模型返回：

```text
数据库通信连接失败
数据库通信失败
```

统计结果就可能是：

```python
{
    "数据库通信连接失败": 1,
    "数据库通信失败": 1
}
```

这不是 `counter.get()` 出错，而是统计逻辑按照字符串键进行计数，没有自动理解两个名称在语义上是否相同。

可以考虑两种改进方式：

- **规范输出：** 在 Prompt 中规定错误类型必须从固定列表中选择。
- **结果归一化：** 在统计前，将含义相同的类型映射到统一名称。

Prompt 约束能够降低分类不一致的概率，但不能保证完全一致；归一化规则则需要根据实际业务维护。

**核心认知：** JSON 格式正确，不代表业务语义一定正确。AI 应用除了校验输出结构，还需要关注分类一致性和结果质量。
