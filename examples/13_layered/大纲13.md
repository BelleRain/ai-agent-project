## 1. 定义异常

新建 `app/exceptions.py`：

```python
class LogAnalyzeError(Exception):
    """日志分析业务异常"""
    pass


class LLMServiceError(LogAnalyzeError):
    """模型调用异常"""
    pass


class StructuredOutputError(LogAnalyzeError):
    """结构化输出解析异常"""
    pass
```

---

## 2. 把模型调用放进 Service

新建 `app/services/log_service.py`：

```python
from openai import OpenAI

from app.exceptions import LLMServiceError, StructuredOutputError
from app.models import ErrorAnalysis
from config import settings
from prompts import SYSTEM_PROMPT, USER_PROMPT_TEMPLATE


client = OpenAI(
    api_key=settings.api_key,
    base_url=settings.base_url,
)


def analyze_log(log_text: str) -> ErrorAnalysis:
    try:
        response = client.beta.chat.completions.parse(
            model=settings.model_name,
            messages=[
                {
                    "role": "system",
                    "content": SYSTEM_PROMPT,
                },
                {
                    "role": "user",
                    "content": USER_PROMPT_TEMPLATE.format(
                        log_text=log_text
                    ),
                },
            ],
            response_format=ErrorAnalysis,
            temperature=settings.temperature,
        )
    except Exception as exc:
        raise LLMServiceError("模型调用失败") from exc

    message = response.choices[0].message

    if getattr(message, "refusal", None):
        raise StructuredOutputError(
            f"模型拒答：{message.refusal}"
        )

    if message.parsed is None:
        raise StructuredOutputError(
            "模型没有返回可解析的结构化结果"
        )

    return message.parsed
```

这里的核心变化是：

```text
路由层只负责接收请求
Service 层负责调用模型
```

## 3. 统一响应模型

在 `app/models.py` 中增加：

```python
from typing import Literal

from pydantic import BaseModel, Field


class LogAnalyzeRequest(BaseModel):
    log_text: str = Field(
        min_length=1,
        max_length=10000,
        description="待分析的错误日志",
    )


class Evidence(BaseModel):
    log_fragment: str
    explanation: str


class ErrorAnalysis(BaseModel):
    error_type: str
    severity: Literal["low", "medium", "high"]
    confidence: Literal["low", "medium", "high"]
    possible_causes: list[str]
    suggestions: list[str]
    evidence: list[Evidence]


class ApiResponse(BaseModel):
    success: bool
    data: ErrorAnalysis | None = None
    message: str
    warnings: list[str] = []
```

## 4. 编写路由层

新建 `app/routers/log_router.py`：

```python
from fastapi import APIRouter, HTTPException

from app.exceptions import LLMServiceError, StructuredOutputError
from app.models import ApiResponse, LogAnalyzeRequest
from app.services.log_service import analyze_log


router = APIRouter(
    prefix="/api/v1/logs",
    tags=["日志分析"],
)


@router.post("/analyze", response_model=ApiResponse)
def analyze_log_api(request: LogAnalyzeRequest):
    try:
        result = analyze_log(request.log_text)

        return ApiResponse(
            success=True,
            data=result,
            message="分析成功",
        )

    except LLMServiceError as exc:
        raise HTTPException(
            status_code=502,
            detail=str(exc),
        )

    except StructuredOutputError as exc:
        raise HTTPException(
            status_code=422,
            detail=str(exc),
        )

    except Exception as exc:
        raise HTTPException(
            status_code=500,
            detail="服务内部错误",
        ) from exc
```

这里先用 `HTTPException`，明天再改成全局异常处理器。

## 练习 2：把批量接口也纳入分层

在 `app/models.py` 增加：

```python
class BatchLogAnalyzeRequest(BaseModel):
    logs: list[LogAnalyzeRequest]


class BatchItemResult(BaseModel):
    success: bool
    data: ErrorAnalysis | None = None
    message: str | None = None


class BatchLogAnalyzeResponse(BaseModel):
    total: int
    success_count: int
    failure_count: int
    results: list[BatchItemResult]
```

在 `log_router.py` 增加：

```python
@router.post(
    "/analyze-batch",
    response_model=BatchLogAnalyzeResponse,
)
def analyze_batch(request: BatchLogAnalyzeRequest):
    results = []
    success_count = 0
    failure_count = 0

    for item in request.logs:
        try:
            result = analyze_log(item.log_text)
            results.append(
                BatchItemResult(
                    success=True,
                    data=result,
                    message="分析成功",
                )
            )
            success_count += 1

        except Exception as exc:
            results.append(
                BatchItemResult(
                    success=False,
                    message=str(exc),
                )
            )
            failure_count += 1

    return BatchLogAnalyzeResponse(
        total=len(request.logs),
        success_count=success_count,
        failure_count=failure_count,
        results=results,
    )
```

这个练习与你现在做调度平台时的批量任务处理很像：

```text
单条失败 ≠ 整批失败
```
