### 第三步：让 LLM 返回 JSON

先继续使用你昨天已经能够运行的 API 调用方式。

例如：

```
```

```
import json
from pydantic import BaseModel


class ErrorAnalysis(BaseModel):
    error_type: str
    possible_causes: list[str]
    suggestions: list[str]


# 假设这里是模型返回的内容
content = """
{
    "error_type": "数据库连接失败",
    "possible_causes": [
        "数据库地址不可达",
        "数据库服务未启动"
    ],
    "suggestions": [
        "检查数据库服务状态",
        "检查网络连接"
    ]
}
"""

data = json.loads(content)

result = ErrorAnalysis(**data)

print(result)
print(result.error_type)
print(result.suggestions)
```

## 今天一定要理解的区别

昨天的方式：

```
```

```
Prompt
↓
"请返回 JSON"
↓
模型返回一段字符串
↓
你自己 json.loads()
```

今天的目标：

```
```

```
Prompt / Schema
↓
结构化数据
↓
Pydantic Model
↓
程序直接使用
```

也就是说，你后面真正开发 AI 应用时，不应该只是：

```
```

```

```

而是应该开始考虑：

```
```

```
result.error_type

result.possible_causes

result.suggestions
```

然后继续写业务逻辑。

这就是你从“调用一下 AI API”逐渐走向 **AI 应用工程开发** 的关键一步。
