## 2. `config.py`

```python
import os

from dotenv import load_dotenv

load_dotenv()


class Settings:
    api_key = os.getenv("OPENAI_API_KEY")
    base_url = os.getenv("OPENAI_BASE_URL")
    model_name = os.getenv("MODEL_NAME", "")
    temperature = float(os.getenv("TEMPERATURE", "0"))
    max_tokens = int(os.getenv("MAX_TOKENS", "800"))


settings = Settings()
```

这里的作用就是把环境变量转换成程序可以直接使用的配置。

例如：

```text
TEMPERATURE=0.7
```

会被转换成：

```python
settings.temperature == 0.7
```

## 4. `prompts.py`

```python
SYSTEM_PROMPT = """
你是一名资深 Java 后端故障分析工程师。
你需要根据错误日志，输出结构化的故障分析结果。
"""

USER_PROMPT_TEMPLATE = """
请分析下面的错误日志，并返回 JSON：

{{
  "error_type": "简洁的错误类型",
  "possible_causes": ["至少 2 条可能原因"],
  "suggestions": ["至少 2 条解决建议"]
}}

要求：
1. 只返回 JSON
2. 不要输出 Markdown
3. 原因和建议必须结合日志
4. 无法确定的内容要明确说明“需要进一步确认”

错误日志：
{log_text}
"""
```

这里开始把 Prompt 从业务代码中独立出来。

以后修改 Prompt 时，不需要进入 `log_analyzer.py` 修改业务逻辑。

## 5. `log_analyzer.py`

```python
import json

from openai import OpenAI

from config import settings
from models import ErrorAnalysis
from prompts import SYSTEM_PROMPT, USER_PROMPT_TEMPLATE


client = OpenAI(
    api_key=settings.api_key,
    base_url=settings.base_url,
)


def analyze_log(log_text: str) -> ErrorAnalysis:
    user_prompt = USER_PROMPT_TEMPLATE.format(log_text=log_text)

    response = client.chat.completions.create(
        model=settings.model_name,
        messages=[
            {
                "role": "system",
                "content": SYSTEM_PROMPT,
            },
            {
                "role": "user",
                "content": user_prompt,
            },
        ],
        temperature=settings.temperature,
        max_tokens=settings.max_tokens,
    )

    content = response.choices[0].message.content
    data = json.loads(content)

    return ErrorAnalysis(**data)
```

这里可以看到：

```text
settings.model_name
settings.temperature
settings.max_tokens
```

全部来自配置。

因此修改模型和参数时，不需要修改：

```python
analyze_log()
```

的业务逻辑。

## 6. `prompt_eval.py`

把之前的校验和评分逻辑保留：

```python
from models import ErrorAnalysis


def validate_analysis(result: ErrorAnalysis) -> list[str]:
    warnings = []

    if len(result.possible_causes) < 2:
        warnings.append("可能原因少于 2 条")

    if len(result.suggestions) < 2:
        warnings.append("解决建议少于 2 条")

    if len(result.error_type.strip()) < 3:
        warnings.append("错误类型过短")

    return warnings


def score_analysis(result: ErrorAnalysis) -> int:
    score = 100

    if len(result.possible_causes) < 2:
        score -= 20

    if len(result.suggestions) < 2:
        score -= 20

    if len(result.error_type.strip()) < 3:
        score -= 20

    return max(score, 0)
```
